# Lyra v0.25.27 — Sheliak · VFO Step + Helios SWR + Freq Cal

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.26.

## What's new since v0.25.26

- **VFO LED wheel (GitHub #22).** Wheel on a digit moves that place.
  Wheel on the LED but not on a digit uses that VFO's Tuning **Step**
  (VFO A and VFO B each have their own). **Snap VFO wheel to Step**
  (Settings → Hardware → Navigation, default off) applies on that
  empty-LED path, the USB encoder, and the panadapter wheel. Panadapter
  wheel stays Display **Panafall**; panadapter click stays **Exact /
  100 Hz**.
- **Helios TX SWR.** On transmit the SOL readout is watts, then **SWR**,
  then the planet name (for example WORMHOLE). MIC / ALC / GAIN chips
  are unchanged.
- **View → Freq Cal (GitHub #21).** Opens the same floating panel as the
  Freq Cal chip. Settings → Calibration is unchanged.

## If it misbehaves

Reinstall **v0.25.22** from GitHub. Settings stay. **v0.25.26 Sheliak**
is the previous public build.

## Install

Download **Lyra-Setup-0.25.27.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
