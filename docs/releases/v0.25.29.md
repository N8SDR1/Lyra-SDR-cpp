# Lyra v0.25.29 — Sheliak · OC on P2 + Help balloon

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.28.

## What's new since v0.25.28

- **OC Control follows Thetis / DeskHPSDR.** Settings → **Filters / BCD**
  emits the pin ticks **you** set. Protocol 1 still uses I2C `0x20`;
  Protocol 2 now sends the same 7 bits on high-priority **`[1401]`**
  (was stuck at 0). Accessory is **Off / N2ADR / Custom**, **per rig**.
  Hermes Lite defaults to N2ADR; Brick / ANAN default **Off** (onboard
  LPFs are Alex). Named **Xvtr** rows default empty so an HF amp on J16
  does not follow a 10 m IF. **Example Yaesu A–D** is an optional
  starting grid only — Lyra does not auto-map Yaesu BCD onto a Brick or
  ANAN DB9 (Brick 2 vs Brick 3 pinouts differ).
- **USB-BCD (FTDI)** is unchanged: PC cable, Yaesu codes, including
  60 m → 40 m and 11 m → 10 m. Bench: HL2, Brick 2, and Brick 3 RX hops
  with a VK Yaesu-coded amp.
- **Parked Help balloon.** Hover help is one draggable glass bubble
  (remembers the spot). Drive / TUN / MOX / band chips stay clickable.
  Solar / Propagation chips keep the old under-chip tip.
- **Ham 6 m hidden on Protocol 1** (no native 6 m on HL2). Use an Xvtr
  slot. Protocol 2 still shows 6 m.
- **PureSignal / Amp View** remember floating size. P2 collect no longer
  sticks when FB stays 0.

## If it misbehaves

Reinstall **v0.25.28** from GitHub. Settings stay. **v0.25.22** remains
the long return point.

## Install

Download **Lyra-Setup-0.25.29.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
