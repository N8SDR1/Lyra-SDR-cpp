Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).

## Summary

- **QRV board (opt-in, default off).** Settings → Network → Enable QRV
  board. Publish call, band, mode, and app while the radio is running.
  Exact Hz is a second checkbox, default off. The service issues an
  install key on first heartbeat.
- **Toolbar QRV chip** immediately after **Apps**. Same floating panel as
  **View → QRV** (PS-style). **QRV** publishes; **QRT** (button, disable,
  disconnect, or quit) removes you from the roster.
- **Not Discord.** Lyra never sends a Discord bot token. Operators already
  watching **#qrv** see call / band / mode / app from the same board.
- **Unchanged:** WDSP 2.11 + CW NNR models (0.25.42). ASIO for VAC in
  test (0.25.41). ANAN / Brick3 filters on Filters / BCD (0.25.40).

## How to use QRV

1. Settings → Network → tick **Enable QRV board**. Check the callsign.
2. **▶ Start** the radio.
3. Click the **QRV** chip (after Apps) or **View → QRV**.
4. Press **QRV** on the panel. Heartbeats go to
   `https://qrvsdr.cc/v1/*.php` about every 30 s.
5. Press **QRT** when you leave. Tick **Share exact frequency** only if
   you want Hz on the HTTPS roster (never on Discord).

## What testers should try

Leave QRV off and confirm nothing hits the network. Enable, Start, QRV,
see yourself on the panel and at qrvsdr.cc / Discord **#qrv**. QRT and
quit should drop the row. Hz share stays off unless you tick it. Report
issues with a log from `%APPDATA%\N8SDR\Lyra-cpp\logs\lyra-log.txt`.

## If it misbehaves

Reinstall **v0.25.42** from GitHub. Settings stay. **v0.25.22** remains
the long return point. Leave QRV Enable off if the board is the problem.
