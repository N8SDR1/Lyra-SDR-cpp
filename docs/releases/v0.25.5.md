# Lyra v0.25.5 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.4.

## What's new

- **HID USB encoder** — Settings → Hardware → Navigation. A mouse-wheel
  style 1-knob USB encoder tunes the focused VFO by the Tuning **Step**.
- **FM 1750 Hz TX burst** — while keyed, tap **1750** on the Tuning dock:
  ~0.5 s of 1750 Hz mixed into FM TX audio. Chip is shown for IARU
  Region 1 (Hardware override for other regions).
- Extra VFO steps **6.25 / 8.33 / 12.5 kHz**. FM RPT offset typed in kHz;
  **7.6 MHz** preset for 70 cm (−7600 kHz typical).
- RX EQ dock title no longer reads as TX EQ.
- Help: MIDI is **not** native — use a MIDI→TCI sidecar from
  **Settings → Apps** (Lyra TCI default **40001**). No in-app GitHub
  download of a MIDI sidecar in this cut.
