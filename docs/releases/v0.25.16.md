# Lyra v0.25.16 — Sheliak · Brick3 Beta Testing

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. The testers' label is **Brick3 Beta
Testing** — dummy load first on Brick3.

Star name stays **Sheliak**. Patch over v0.25.15.

## What's new since v0.25.15

- **Brick3SDR (Protocol 2) — beta testing.** Discovery MAC `02:B3` shows
  as Brick3. Pick **Brick3SDR** in Settings → Hardware (not Hermes-class
  BrickSDR). RX + TX, SUB / SPLIT, PureSignal on the rear **PS** jack.
  Dummy load + Arm P2 TX on first key.
- **MAP** — per-band ANT + RX jack chips. Brick3: 2 ANT, RX2 = Ext1
  (protocol bit 9). 7000 / 8000 / G2 keep 3 ANT + RX ports in the catalog.
- **Auto Step** — Protocol 2 ADC pad 0–31, frozen while keyed, quiet
  unwind toward 0. Overflow is gated on the selected ADC (no walk to
  −30 on a quiet band).
- **Per-band PureSignal pad** — last ATT is stored per TX band
  (`ps/txAtt/<band>`) and restored when you change band.
- **PS Reset** — Restart actually holds WDSP reset. Clears st / cal /
  correcting and Amp View in **RX or TX**. ATT is left as-is. FB is the
  live coupler (near 0 in RX).
- Plug the sampler / coupler return into the Brick3 rear **PS** jack —
  that is the coupler path Thetis uses. There is **no** Internal / EXT1
  picker (MAP RX2 is a receive jack, not that switch).
