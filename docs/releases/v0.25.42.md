# Lyra v0.25.42 — Aladfar · WDSP 2.11

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name **Aladfar** (η Lyrae), next
after Sulafat. Patch over v0.25.41. Build date **2026-11-14**.

Installer app identity stays **Lyra-cpp** (same QSettings as Sulafat).
Install over 0.25.41; settings stay.

**Scope:** bundled DSP is **WDSP 2.11** (Warren Pratt NR0V, official
TAPR release, 2026-10-15). **ASIO for VAC remains in test** (shipped
in v0.25.41, default **off**). Qt speaker **Out** and the HL2 jack are
unchanged. This is **not** Thetis CMASIO and **not** a WING used as the
radio mixer.

## Summary

- **WDSP 2.11.** Same host bindings as 2.10, plus engine updates to
  AGC, classic NR (EMNR), the auto-notch (ANF), the FM demodulator, and
  PureSignal calibration. `GetWDSPVersion` returns **211**.
- **CW models for NNR.** Four neural models: Standard and Premium for
  voice, plus Standard and Premium trained on CW. The NNR control still
  offers Standard / Premium. In **CWU / CWL**, Lyra uses the CW version
  of the chosen model automatically (RX1 and RX2 separately) and
  switches back on a mode change.
- **One-time FFT optimization.** The first start after updating shows
  **Optimizing FFT plans** for a few minutes while the FFT cache is
  rebuilt for the new engine. Later starts are normal.
- **Unchanged:** ASIO for VAC in test (0.25.41). ANAN / Brick3 filters
  on Filters / BCD (0.25.40). HiDPI / Log-on-screen (0.25.39). DeepFist
  pitch lock (0.25.38). 7000DLE / 8000DLE TX, Xvtr BYTE0–4, Metis STOP.
  G2 dummy-load arm. Protocol 1 ANAN refused.

## What testers should try

Start once and let the FFT splash finish. Switch NNR Standard / Premium
in USB, then in CWU/CWL — CW should use the CW-trained pair without a
new control. Confirm `[wdsp] LOADED` in the log. ASIO for VAC is still
optional and still **test**. Report issues with a log from
`%APPDATA%\N8SDR\Lyra-cpp\logs\lyra-log.txt`.

## If it misbehaves

Reinstall **v0.25.41** from GitHub. Settings stay. **v0.25.22** remains
the long return point. If ASIO itself misbehaves, leave Enable off.
