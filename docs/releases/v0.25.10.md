# Lyra v0.25.10 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.9.

## What's new

- **HL2 analog band-follow is independent of N2ADR OC.** Protocol 1
  always writes TX frequency so analog filters follow the band. The
  **Enable N2ADR / IO board** checkbox only drives OC / LPF relays.
- **NR-C panadapter stays rectangular.** Audio still uses the captured
  profile. The spectrum stays on uncleaned IQ, so a strong station does
  not paint a 70–90 kHz slope. Occupied-bin mix is off. Floor default
  **−24 dB** (older −12 migrates).
- **Session recorder.** RX WAV on Protocol 1 and Protocol 2. Panadapter
  snapshots work on Vulkan (then screen, then widget).

NNR Standard, PWR peak-hold, TCI CW terminal, and TX sensors from
0.25.9 are unchanged. WDSP 2.10 from 0.25.8.
