# Lyra v0.25.4 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.3.

## What's new

- **Apps** — Settings list and header chip for named third-party programs
  (WSJT-X, fldigi, SSTV, loggers, …). Auto-start default **off**; when
  enabled, launch is after Hardware Startup (radio + audio).
- **Native RTTY decoder removed.** Digital modes stay in companion apps
  over TCI or VAC. **CW send and CW receive decode stay in Lyra.**
  DX-cluster RTTY *spot labels* are unchanged.
- **Memory editor** — click a cell in Settings → Bands → Memory (Enter /
  leave the cell to keep; no Save button). Repeater Offset / UL / DL /
  Burst as before.
- **Xvtr** — out-of-band IF clamp on the VFO removed (you keep IF in the
  radio window). Ten-digit RF display from v0.25.3 is unchanged.
