# Lyra v0.25.0 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

Star name: **Sheliak** (β Lyrae) — unused until now. Vega stays the
identity / watermark star, not a version label.

This is the **PureSignal** release: adaptive TX predistortion on coupler-mod
HL2 / HL2+ and BrickSDR2 (ADC0 pad), plus **Amp View**.

## PureSignal

- Compact **PureSignal** dock: arm, 2-tone, FB glance (teal / green / red
  zones), auto-att readout.
- **Amp View** dock: GetPSDisp plasma plot, Snap / Hold, extras (txrx, mag,
  phc, phs, sln.chk, rxs, dg.cnt).
- Auto-att **persists across PTT** — SSB does not re-hunt every keyup.
- Attestation in **Settings → TX** (default off). HL2 / HL2+ needs the
  coupler mod; BrickSDR2 uses the ADC0 feedback pad.
