# Lyra v0.25.14 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.13.

## What's new

- **TCI TUNE / TRX / CHRONO restored.** TUNE keys the TX-panel **TUN**
  path. TRX keys **MOX** the same way the host MOX button does. CHRONO
  TX-audio frames use the negotiated rate, sample count, format, and
  channel count. A TCI socket flicker no longer unkeys. Operator bench:
  MSHV, WSJT-X, JTDX, SDRLogger+. TUNE/TRX still need **▶ Start**.

v0.25.13 STOP-does-not-drop-MOX, v0.25.12 Rec folder, and v0.25.11
FFTW-before-companions stay in this tree.
