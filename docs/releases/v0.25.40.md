# Lyra v0.25.40 — Sheliak · ANAN / Brick3 filters on Filters / BCD

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.39. Build date **2026-11-14**.

**Scope:** Settings → **Filters / BCD** now shows the Protocol 2
**ANAN / Brick3** radio's own Alex filters (RX high-pass or band-pass,
TX low-pass, antenna) as read-only lamps and grid ticks. Hidden on
HL2 / BrickSDR. **HiDPI display** is already in v0.25.39. **DeepFist**
pitch lock is already in v0.25.38.

## Summary

- **Radio filters on Filters / BCD.** ANAN / Brick3 band filters are
  switched by the per-packet Alex words, not the J16 OC pins, so
  **Live pins** stayed dark while the relays clicked. The same tab now
  shows them read-only beside the J16 pins: a lit lamp row under Live
  pins, and ticked per-band columns in the OC grid. Decoded from the
  same functions that build the words sent to the radio. Display only.
- **Hidden for HL2 / BrickSDR.** No Alex-driven front-end to show
  (BrickSDR: onboard filters, automatic).
- **Orion MkII receive packet.** The 7000DLE / 8000DLE profile now
  sends the Alex1 TX image (TX LPF + antenna + T/R relay when the PA
  is on) in receive too, as deskHPSDR does. Transmit is unchanged.
  Not shown to be required on the Cyclone V 7000 that prompted it.
- **Unchanged:** HiDPI display and Log-on-screen (0.25.39). DeepFist
  pitch lock (0.25.38). 7000DLE / 8000DLE / Orion MkII /
  Anvelina-Pro3 TX, Xvtr BYTE0–4, Metis STOP. G2 dummy-load arm.
  Protocol 1 ANAN refused. J16 OC bits are the same as 0.25.39.

## Filters / BCD

On a Protocol 2 ANAN or Brick3, open Settings → **Filters / BCD**.
Under **Live pins** you should see RX HPF (classic Alex) or RX BPF
(Orion MkII / Saturn), TX LPF, and ANT1/2/3 follow the dial. The
per-band grid columns tick the same way. You still pick antenna and
HPF bypass on the Band dock — these columns are not switches.
