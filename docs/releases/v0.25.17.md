# Lyra v0.25.17 — Sheliak · dual-ADC SUB pane

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.16.

## What's new since v0.25.16

- **Second spectrum on two-converter radios.** Brick3SDR, ANAN-100D /
  200D (and other **adcCount > 1** boxes) open a **SUB panadapter** when
  **SUB** is on — own waterfall, band-plan markers, click-tune. HL2 /
  BrickSDR2 still draw RX2 as the green overlay on the main pane.
- **SUB RX floor / ceiling** — Settings → Visuals, two extra rows on
  dual-ADC radios. One pair drives SUB pan **and** SUB waterfall.
  Remembered **per RX2 band**. Main RX / TX dB stays independent.
- **SUB layout** — optional **Use a saved layout when SUB is on**. Off
  (default): SUB splits the pan in place without stretching docks. On:
  recalls a named View → Layouts slot. SUB off always restores the
  layout that was running just before.
- **Click-tune.** SUB on: SUB pane tunes **RX2**. SUB + SPLIT: SUB pane
  moves **VFO B** only.
- **Brick3 TX** keys like BrickSDR2 (Enable PA + MOX + Drive — no
  dummy-load arm). Still **beta**: first RF into a dummy load.
- **ANAN Protocol 2 TX mapping.** ANAN-10 / 10E = BrickSDR2 TX.
  ANAN-100 / 100B / 100D / 200D = Brick3SDR TX (on-air, independent
  Enable PA). G2 still dummy-load arm. 7000DLE / 8000 stay locked.
- **PureSignal dock** — ON, 2-tone, **Voice**, ATT, FB, Reset. Engine
  chips (st / cal / D0 / D1) live on Amp View.
- **Windows per-app mixer** for Lyra is remembered across Stop / Start.

## Already in previous versions, still here

Brick3 MAP / Auto Step / per-band PS pad (v0.25.16), Protocol 2 TX
follows the VFO (v0.25.15), keyboard VFO, startup profiles, SUB / SPLIT,
PureSignal on HL2 / Brick2, TX rack.

## Install

Download **Lyra-Setup-0.25.17.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.
