# Lyra v0.25.26 — Sheliak · layouts + VFO snap

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.25.

## What's new since v0.25.25

- **Layouts (GitHub #20).** Factory recall survives a restart until you
  move a panel. Named slots remember which docks were open. Uninstall
  does not wipe layout (`%APPDATA%\N8SDR\Lyra-cpp` and
  `HKCU\Software\N8SDR\Lyra-cpp`). After install: **View → Layouts →
  Recall → Lyra default**, close, reopen. `--safe` starts factory
  without touching the saved slot. Do not wipe AppData — analog /
  GPA100 settings live there.
- **Snap VFO wheel to Step** — Settings → Hardware → Navigation,
  default off. First wheel notch lands on the grid in that direction.
  LED and USB encoder use Tuning Step; panadapter wheel uses Panafall
  step. Digit-place wheel and click unchanged.
- **Laptop Tuning row.** Lyra logo matches the VFO boxes so SPLIT / RIT
  sit fully on a short dock.

## If it misbehaves

Reinstall **v0.25.22** from GitHub. Settings stay. **v0.25.25 Sheliak**
is the previous public build.

## Install

Download **Lyra-Setup-0.25.26.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
