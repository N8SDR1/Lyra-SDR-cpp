Install over 0.25.47; settings stay.

## Summary

- **HamQSL hourly.** The Solar / Propagation strip fetches N0NBH's
  HamQSL feed at start and about every **60 minutes** (matching HamQSL's
  own cadence).
- **PROP 80–10 m.** Heat-map chips are 80 through 10 metres. **160 m**
  and **6 m** stay on the Band panel — HamQSL has no rating for them.
- **Settings opens without stalling the radio.** Tabs are built on first
  visit instead of all at once, so the first open no longer hitches the
  radio for ~2.5 s.
- **Unchanged:** TCI audio vs AF, VAC with one device, User Guide search
  (0.25.47). TCI/CAT start on Protocol 2 and startup / exit crash fixes
  (0.25.46). Wheel after a drop-down (0.25.45). WDSP 2.11 (0.25.42).
  ASIO for VAC in test (0.25.41).

## What testers should try

- Leave Lyra running: PROP SFI / A / K and band colours refresh about
  once an hour without restarting.
- Confirm the PROP strip has **80 … 10** only — no 160 or 6 chips.
- With the radio running, open Settings the first time in a session:
  audio and panadapter should keep going while the dialog appears.
