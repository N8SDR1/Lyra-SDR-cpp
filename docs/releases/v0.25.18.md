# Lyra v0.25.18 — Sheliak · analog latch · RX2 isolate

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.17.

## What's new since v0.25.17

- **HL2 analog band-follow (J4 pin 8).** Leftover I2C writes from the
  previous band are dropped. The Pico latches when **BYTE0** of the new
  TX-Hz burst is on the wire, so a fast 80 m → 20 m hop should not leave
  20 m stuck on 80 m voltage.
- **RX2 jack isolate on TX** (two-converter radios: Brick3SDR,
  ANAN-100D / 200D, G2). Default **on**. Grounds/disconnects the RX2
  jack while keyed. ATT-on-TX still pads both ADCs; it does not open
  that analog path.
- **11 m / CB on the SUB pane.** Channel chips match the main
  panadapter. Click-tune mode follows **Settings → Hardware → Region**
  (AM vs USB/LSB).

## Radios this installer opens

| Radio | Protocol | Notes |
|---|---|---|
| **Hermes Lite 2 / 2+** | 1 | Full RX + TX. Analog J4 / Pico IO. |
| **BrickSDR2** | 2 only | Full RX + TX, SUB overlay, PureSignal. |
| **Brick3SDR** | 2 only | **Beta.** Second SUB panadapter. First RF: dummy load. |
| **ANAN-10 / 10E** | 2 | TX like BrickSDR2 (on-air). One ADC. |
| **ANAN-100 / 100B** | 2 | TX like Brick3SDR (on-air). One ADC. |
| **ANAN-100D / 200D** | 2 | TX like Brick3SDR + SUB second pane. |
| **ANAN-G2 / G2-1K** | 2 | Dummy-load arm until RF validated. |
| **7000DLE / 8000** | — | Locked. |
| Brick / ANAN on **Protocol 1** | 1 | Discover lists; **Open refused**. Flash P2. |

## Already in previous versions, still here

Dual-ADC SUB pane, Brick3 TX like BrickSDR2, ANAN 10 vs 100-series
mapping, compact PureSignal dock, Windows mixer persist (v0.25.17).
MAP / Auto Step / per-band PS pad (v0.25.16).

Download **Lyra-Setup-0.25.18.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.
