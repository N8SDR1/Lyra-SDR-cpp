# Lyra v0.25.25 — Sheliak (Lyra to Lyra: desk RX2 and CW)

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater sees it.
It sits on top of the **v0.25.24 Sheliak** release.
**v0.25.22** remains the return point if this beta misbehaves.

## What this adds

Desk RX2 picture and audio when the host **SUB** is on and the radio
has its own second converter. A single-converter **SUB** sends RX2
audio and no second picture. CW decoder on the desk, the host CW
pitch on the desk VFO, marker, and passband, and CW chip **Send**
that makes RF on a Protocol 2 Brick. Power is the Drive slider. The
Tune button stays off. MSHV left running holds RF.

The away desk picture stays at about **60 Hz** so the link can carry
audio, keying, and controls.

## Same rules

Tailscale only. Password on every new connection. **Start voice**
before transmit. One desk.

While the host is in CW, Start voice, the key, MOX, Tune, and 2-tone
stay off at 150 ms or more. Outside CW, voice, MOX, Tune, and 2-tone
stay off at 200 ms or more.

Plan on at least 50 Mbps at each end. Not a phone, not a tether, and
not the browser TCI remote.

Steps: [User Guide → Lyra to Lyra](../help/USER_GUIDE.md#lyra-to-lyra).
Wiki: [Lyra to Lyra](https://github.com/N8SDR1/Lyra-SDR-cpp/wiki/Lyra-to-Lyra).

## If it misbehaves

Reinstall **v0.25.22** from GitHub. Settings stay. That build has no
Lyra to Lyra. **v0.25.24 Sheliak** remains the previous public build.

## Install

Download **Lyra-Setup-0.25.25.exe**. Windows 10 / 11. Install this
same version on both PCs.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
