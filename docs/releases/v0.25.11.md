# Lyra v0.25.11 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.10.

## What's new

- **First-run FFTW vs Hardware Startup.** Companion auto-start
  (SDRLogger+, Apps auto-start, two generic slots) waits until the FFT
  plan cache and the radio layer are up. A 0.25.10 first launch could
  start Logger while FFTW was still building; Lyra then vanished.
  Let optimizing finish — Lyra stays open, then Logger starts.
- **TCI handshake and STOP.** Handshake sends `start` only when the
  radio session is running; otherwise `stop` then `ready`. TCI STOP
  does not close the radio (it used to map onto Lyra Stop). Dropped
  TCI TX audio unkeys. TUNE/TRX are refused until **▶ Start**.
- **HL2 analog IO** skips a redundant same-Hz write on a fast return
  to the same band (under half a second).

NR-C rectangular panadapter, Rec WAV + snapshots, analog band-follow
independent of the N2ADR OC checkbox, NNR Standard, PWR peak-hold, TCI
CW terminal, and TX sensors from 0.25.8–0.25.10 are unchanged.
