# Lyra v0.25.8 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.7.

## What's new

- **WDSP 2.10** — bundled NR0V engine (`GetWDSPVersion` 210). FFT wisdom
  file is `wdspWisdom01`; first start after the update may re-run
  optimization once.
- **NNR** — Audio panel neural noise reduction (default off). **Premium**
  model by default; **Standard** also listed. **Mask** slider −10 dB
  (least) to −50 dB (most), default −40. NNR and classic **NR** (EMNR
  Modes 1–4) are exclusive. **NR-C** (captured profile) stays independent.
- **PureSignal Amp View** — re-proved on HL2 (Protocol 1) and Brick
  (Protocol 2). Display fetch is version-gated for the 2.10 ABI.

TCI handshake and Apps recommended links from 0.25.7 are unchanged.
