# Lyra v0.25.20 — Sheliak · Diversity · band stack

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.19.

## What's new since v0.25.19

- **Diversity** mixes the two converters on one frequency. Confirmed on
  **Brick3SDR**; the same path is **ANAN-100D / 200D**. The **DIV** chip
  opens the dock (size and position are remembered); **ON** inside the
  dock arms the mix. Second RF is the **RX2 jack** (Ext1), not ANT2.
  Gain **−27…+27 dB**, phase **−180…+180°**, remembered per band. The
  mix drops while you transmit or while PureSignal is live, and returns
  when you unkey. Turning Diversity on turns **SUB** off. HL2 and
  BrickSDR2 have one converter and do not show the chip.
- **Band stack.** Each band chip stores three frequencies (corner digit
  **1 / 2 / 3**). A click from another band returns the slot you last
  used and does not skip. A second click on the band you are already on
  steps to the next. SUB has its own three. Solar chips tune VFO A to
  the current slot and do not step it.
- **Separate RX and TX filter lows.** Filters dock, under the
  bandwidths (**RX lo** / **TX lo**, 0–500 Hz). The lock keeps them
  together; unlock and they stay apart. Older profiles copy the old
  shared low onto both sides.
- **Issue #17.** Filter-board voltage follows the band you selected,
  including a return to a band already showing on the dial.

## Radios this installer opens

| Radio | Protocol | Notes |
|---|---|---|
| **Hermes Lite 2 / 2+** | 1 | Full RX + TX. |
| **BrickSDR2** | 2 only | Full RX + TX, SUB overlay, PureSignal. |
| **Brick3SDR** | 2 only | **Beta.** Second SUB panadapter. Diversity. First RF: dummy load. |
| **ANAN-10 / 10E** | 2 | TX like BrickSDR2 (on-air). One ADC. |
| **ANAN-100 / 100B** | 2 | TX like Brick3SDR (on-air). One ADC. |
| **ANAN-100D / 200D** | 2 | TX like Brick3SDR + SUB second pane + Diversity. |
| **ANAN-G2 / G2-1K** | 2 | Dummy-load arm until RF validated. |
| **7000DLE / 8000** | — | Locked. |
| Brick / ANAN on **Protocol 1** | 1 | Discover lists; **Open refused**. Flash P2. |

## Install

Download **Lyra-Setup-0.25.20.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.
