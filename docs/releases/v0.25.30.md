## What's new since v0.25.29

- **Xiegu / XPA125 / Micro PA50** take band from the I/O-board PIC as
  a **voltage on J4 pin 8**. Not J16 OC. Not USB-BCD. Leave
  **Settings → Filters / BCD → Band Volts on J3** **Off** (J3 is the
  fan header).
- **`LYRA_NO_IOBOARD_FCODE=1`** how-to in Help: Windows **user**
  environment variable (not a Settings box). Skips Pico registers
  **13 / 14** only. Analog J4 and RF1 / Alt stay. Includes how to
  delete it afterwards.
- **CW keyer** remains KEY jack + **Settings → CW → CW key over COM
  port**. No extra Winkeyer USB driver (same as Thetis / DeskHPSDR).
