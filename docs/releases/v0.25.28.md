# Lyra v0.25.28 — Sheliak · IO-board RX fcodes + PS ON

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.27.

## What's new since v0.25.27

- **HL2 IO-board RX fcodes (GitHub #23).** Writes Ahlstrom / deskHPSDR
  one-byte RX codes to Pico I2C2 `0x1D` registers **13** and **14**
  from the **VFO dial** (not the transverter IF). That is what a
  Pico GPIO / DB9 decoder uses **in receive**. Analog **BYTE0–4**
  (GPA100 / J4 PWM) and **RF1 / Alt** (register 11 = 0 or 2 only)
  are unchanged.
- **PureSignal dock ON.** One daily switch, like Thetis / DeskHPSDR.
  First ON records Settings → TX coupler installed. Watts cap, Drive,
  PA Gain, and ATT-on-TX are not on that path.

## If it misbehaves (Volker / Randy / GPA100)

**v0.25.27** stays on GitHub — reinstall that installer. Settings stay.

Pico GPIO only, analog still fine: set a user environment variable
**`LYRA_NO_IOBOARD_FCODE=1`**, restart Lyra. That skips registers 13/14
and leaves BYTE0–4 and RF1/Alt alone.

Long return point remains **v0.25.22**.

## Install

Download **Lyra-Setup-0.25.28.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.
