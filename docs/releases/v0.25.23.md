# Lyra v0.25.23 — Sheliak (Lyra-to-Lyra beta)

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater sees it.
Star name notes the beta. **v0.25.22** remains the return point.

## What to try

This is a beta of a second Lyra operating the shack rig over Tailscale.
The shack stays on the radio. The laptop attaches and does not open its
own radio. Install this same version on both PCs.

Start at **Settings → Remote**, or **Rig → Remote**. Tailscale:
<https://tailscale.com/download>. Same personal account on both PCs.
Use the shack MagicDNS name. No Funnel, no port-forward, no public IP.

Try attach, receiver audio, spectrum, tune, voice, PureSignal on/off,
2-tone, desk profile recall, and TCI on the laptop for JTDX, MSHV, or
Open SSTV at `127.0.0.1` port `40001` after **Start voice**.

Round trip: CW under 150 ms, voice under 200 ms. Listening stays up
past that.

Operator steps: [User Guide → Lyra to Lyra](../help/USER_GUIDE.md#lyra-to-lyra).

## If it misbehaves

Reinstall **v0.25.22** from GitHub. That build has no Lyra-to-Lyra.
Settings stay.

## Install

Download **Lyra-Setup-0.25.23.exe**. Windows 10 / 11.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
