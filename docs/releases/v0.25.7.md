# Lyra v0.25.7 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.6.

## What's new

- **TCI handshake** — advertise ExpertSDR3 / SunSDR2PRO, emit `start;`
  then `ready;`, and echo the client's own `start;` / `stop;`. WSJT-X
  and JTDX no longer report “TCI SDR is not switched on.” MSHV and Open
  SSTV still connect. Operator-confirmed: RX and key-up on **MSHV**,
  **WSJT-X**, and **JTDX**. Default port **40001** (WSJT templates often
  still say 50001 — match Lyra).
- **Apps recommended links** — Settings → Apps: Open SSTV, MSHV /
  WSJT-X, VarAC, midi2tci. Lyra does not ship those programs.
