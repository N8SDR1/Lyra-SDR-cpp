# Lyra v0.25.41 — Sulafat · ASIO for VAC (test stage)

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name **Sulafat** (γ Lyrae), next
after Sheliak. Patch over v0.25.40. Build date **2026-11-14**.

Installer app identity stays **Lyra-cpp** (same QSettings as Sheliak).
Install over 0.25.40; settings stay.

**Scope:** optional **ASIO for VAC** is in **test**. Default **off**.
Qt speaker **Out** and the HL2 jack are unchanged. This is **not**
Thetis CMASIO and **not** a WING used as the radio mixer.

## Summary

- **ASIO for VAC (test).** Settings → Audio → **Enable ASIO devices for
  VAC**, then restart. VAC Driver can be **ASIO**. Use the **same**
  driver for Input and Output (full duplex: mic in + RX out). Channel
  pickers, block size, **Hold the rate ratio at 1.0**. 48 kHz.
- **Crash guard.** If Lyra did not finish starting while loading ASIO,
  Enable is forced off.
- **Still not:** CMASIO, ChannelMaster 48-channel routing, parking RX
  on WING channel 17 / TX from an arbitrary bus.
- **Unchanged:** ANAN / Brick3 filters on Filters / BCD (0.25.40).
  HiDPI / Log-on-screen (0.25.39). DeepFist pitch lock (0.25.38).
  7000DLE / 8000DLE TX, Xvtr BYTE0–4, Metis STOP. G2 dummy-load arm.
  Protocol 1 ANAN refused.

## What testers should try

Tick Enable ASIO devices for VAC, restart, pick your ASIO driver on
VAC1 (or VAC2), same device in and out, 48 kHz. Watch VAC Monitor
(TO VAC / FROM VAC around mid, 0 ovf / 0 unf). Close any other
program using that ASIO driver first. Report issues with a log from
`%APPDATA%\N8SDR\Lyra-cpp\logs\lyra-log.txt`.

## Detail

- `e4b43cf` ASIO devices for VAC (opt-in, PortAudio host, SDK 2.3.4
  GPLv3 option).
- `5174bfa` Small driver blocks, pinned rate ratio, channel choice.
- `8073a8f` Re-centre VAC rings once the stream has settled.

## If it misbehaves

Reinstall **v0.25.40** from GitHub. Settings stay. **v0.25.22** remains
the long return point. If ASIO itself misbehaves, leave Enable off.

pick your radio. Installs over 0.25.40; settings stay.
