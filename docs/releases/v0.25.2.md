# Lyra v0.25.2 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.1.

## What's new

- **NR-C restore** — last saved captured-noise profile loads on restart.
  NR-C starts **on** only if it was on at exit. Rate mismatch stays off
  with a recapture hint.
- **TUNE / 2-tone frequency** — carrier at the **dial** on USB / LSB /
  DIG. **CW TUNE** sits on the RX marker, same as keyed CW. Voice **MOX**
  was already correct.
- **TX span matches RX** — the TX panadapter uses the same Hz window as
  RX at the same Zoom (sip1 is 96 kHz; RX IQ is often 192 kHz). Zoom 1×
  at 192 kHz RX still cannot show more than 96 kHz on TX.
