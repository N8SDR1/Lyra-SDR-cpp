# Lyra v0.24.2

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

A patch on v0.24.1: **SUB / RX2 on BrickSDR2**, discovery firmware that
matches deskHPSDR, and VAC TX that does not steal a TCI digital path.

## BrickSDR2 dual receive (SUB)

- Second DDC (DDC1 / radio UDP 1036) with its own panadapter overlay,
  waterfall, and audio when **SUB** is on.
- Click the off-span **◀ RX2 / RX2 ▶** emblem to jump the panadapter to
  that receiver’s frequency (and the other way).
- Brick firmware that still discovers as “Hermes” keeps a **Brick** label
  in Settings; the Connected line uses the real model, not Saturn.

**Brick gateware:** dual RX needs a current Brick2 FPGA image (the
deskHPSDR-era Brick2_14b class). Same MAC after a flash is normal; the
firmware code is what moved.

## Discovery firmware (deskHPSDR-parity)

Protocol 2 replies now format firmware as **v{code/10}.{code%10}**
(optional `.{beta}`), so a Brick at code 106 shows **v10.6**, not
“fw v0, 0 DDC”. A zero DDC count in the reply is treated as **2**
receivers. 1444-byte IQ datagrams are ignored on the discovery socket.

## VAC TX vs TCI

- **Enable VAC1** starts the VAC engine (RX → PC). It does **not** by
  itself put VAC on the transmitter.
- Transmit from a cable: **Settings → TX → Mic source = PC Soundcard
  (VAC1)** (or tick **Use VAC1 as TX source**), plus VAC **Input** =
  the cable your app plays into. Use **DIGU / DIGL** if
  **Auto-enable for digital** is on — USB turns that auto path **off**.
- **TCI audio is exclusive.** If Mic source is **TCI**, Lyra will not
  also arm VAC TX. Logger/digital apps that send TX audio over TCI keep
  that path.

## Other

- Single-instance: if the previous-instance ping fails, Lyra **starts
  anyway** (a leftover hung process no longer blocks launch). You still
  do **not** need to “Run as administrator” to start — the installer
  writes firewall rules for discovery.
- Waterfall-ID exit restores the same TCI-vs-VAC TX rule as a normal
  session.
