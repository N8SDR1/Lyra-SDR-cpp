Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).

## Summary

- **TCI audio no longer follows the AF slider.** AF now only sets your
  own listening level, so turning it up no longer overdrives WSJT-X,
  JTDX, STD or other TCI programs.
  **If you had lowered Settings → Network → TCI RX-out gain to make up
  for AF (often around −20 dB), set it back to 0.0 dB** and set the
  level in your program's own RX / input gain. It's a big level change,
  so expect to readjust once. (Bench: Lyra RX-out 0.0 dB with STD RX
  gain +10 dB.)
- **VAC with only one device.** VAC1 and VAC2 now start with only an
  **Output** device (RX audio to a digital program) or only an **Input**
  device (a PC mic for transmit), with the other set to **(none)**.
  Before, leaving Input at (none) stopped the whole cable, so no RX audio
  reached the program either. A device you named that is missing still
  stops the cable, as before.
- **Search the User Guide.** Help now has a **Search the guide** box above
  the contents (Ctrl+F). The list shows the sections that contain all of
  your words, with a match count, and every match is highlighted.
  **Enter** / **F3** steps to the next match, **Shift+Enter** /
  **Shift+F3** to the previous one, **Esc** clears.
- **Unchanged:** TCI/CAT start on Protocol 2 and the startup / exit crash
  fixes (0.25.46). Wheel after a drop-down (0.25.45). WDSP 2.11 + CW NNR
  models (0.25.42). ASIO for VAC in test (0.25.41).

## What testers should try

- Digital modes over TCI: set TCI RX-out gain to 0.0 dB, set the level in
  the program, then move AF — the program's level stays put.
- VAC1 with Output = your cable and Input = **(none)**: RX audio reaches
  the program.
- Help → type a word or two in the search box; click a result, press F3.
