# Lyra v0.25.9 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.8.

## What's new

- **NNR factory model is Standard.** The 0.25.8 installer picked
  **Premium** on a fresh install. This one picks **Standard** (lighter
  CPU). A model you already saved is kept. **Mask** still runs −10 dB
  (least) to −50 dB (most), default −40; the tooltip suggests trying
  **−25 to −40**. NNR stays off until you turn it on, and it still
  cannot run with classic **NR**.
- **PWR needle tracks voice peaks.** Between meter ticks Lyra keeps the
  highest forward-power sample, so a voice peak lands on the needle
  instead of a quiet average. Factory peak-hold for that needle is
  **700 ms** if you have not saved your own.
- **TCI CW terminal.** A logger in terminal mode can hold the key line
  up between letters and correct the callsign mid-send. Prosigns
  (`|SK|`) and speed steps (`<` / `>`) work in the text. Lyra tells the
  client when the queue has drained and when the callsign's last letter
  starts.
- **TCI TX sensors stay live at receive.** Mic level, forward power,
  peak power, and SWR keep updating while you are listening, so a
  client's TX meters do not go blank between overs.

WDSP 2.10, Amp View, and the TCI handshake from 0.25.7 / 0.25.8 are
unchanged.
