# Lyra v0.25.12 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.11.

## What's new

- **Rec default folder is writable.** Sessions go to
  `%USERPROFILE%\Lyra\Recordings`. A Start-Menu launch used to land Rec
  under Program Files (not writable) so Rec looked like it did nothing.
  Empty, relative, or install-folder paths migrate on load.

v0.25.11 (FFTW before companions, TCI STOP, analog same-Hz skip) is in
this tree. Install this if you already have 0.25.11.
