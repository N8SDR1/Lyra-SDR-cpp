# Lyra v0.25.6 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.5.

## What's new

- **HL2 analog band-follow** — with **Enable N2ADR / IO board** on
  (default), analog band voltage on a stock IO board now tracks TX
  frequency correctly. Same behaviour as Thetis / Quisk / SparkSDR.
  Tick the N2ADR box if it was off, then **Start**. Protocol 2
  Brick/ANAN is unchanged. Closes GitHub **#14**.
- Help / wiki Filters / BCD notes updated to match.
