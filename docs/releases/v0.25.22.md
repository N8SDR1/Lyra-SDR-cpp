# Lyra v0.25.22 — Sheliak · meters + TX band guard

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.21.

## What's new since v0.25.21

- **Helios / Sonar / Cluster** meter faces on the same 0…1 as Arc.
  Helios is the sun and planets (S9 = Jupiter). Sonar is the PPI with a
  compass ring (it replaces Radar). Cluster is the cockpit arc and bars.
- **Band change while transmitting** is ignored. You stay keyed. Status:
  *Frequency change ignored while transmitting.* Same-band hops still
  go through.
- **Xvtr** chips recall per-slot LNA (HL2) and ATT (P2).
- **Password required to listen** is disabled until a real RX lock can
  exist without breaking a receiver page or WSJT-X on another computer.
  **Start voice** still uses the password.
