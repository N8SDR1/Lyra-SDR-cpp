# Lyra v0.25.31 — Sheliak · minor PS changes for P2

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.30.

## What's new since v0.25.30

- **Minor PureSignal changes for Protocol 2.** Auto-att follows live
  feedback so a leftover pad cannot starve a calibration. Turning PS
  **ON** turns **ATT-on-TX** on (Thetis Auto Attenuate); PS off restores
  the checkbox. The dB spin is unchanged.

## If it misbehaves

Reinstall **v0.25.30** from GitHub. Settings stay. **v0.25.22** remains
the long return point.

## Install

Download **Lyra-Setup-0.25.31.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
