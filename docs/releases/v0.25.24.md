# Lyra v0.25.24 — Sheliak

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater sees it.
**v0.25.22** remains the return point if you do not want Lyra-to-Lyra.

## What to try

**Hermes Lite + transverter / IO board (Volker).** On Protocol 1 the Band
dock Xvtr row has **RF1** and **Alt**. Leave **RF1** for the PA / N2ADR
antenna SMA. Click **Alt** only if that slot’s IF is on the Pico / IO
**Alt RX** jack. Station table: User Guide → *Which Hermes Lite station
is mine?* Analog GPA100 band voltage on J4 is unchanged.

**Protocol 2 TX.** DUC I/Q (UDP 1029) no longer shares the radio session
thread. Aimed at the occasional “keyed, relay clicks, no RF until restart”
after a long MSHV / WSJT session. Dummy load on the first Brick key after
install.

**Lyra to Lyra**, on top of the 0.25.23 beta. Same version on both PCs.
The desk shows the host second-receiver picture and plays that audio
when **SUB** is on and the radio has its own second converter. A
single-converter **SUB** sends the audio and no second picture. The
away picture stays at about 60 Hz so the link can carry audio, keying,
and controls.

CW from the desk follows the host mode and the host CW pitch, so the
VFO, the marker, and the passband show the same carrier. A straight
key, the serial key, CW chip Send, and the macros tell the host to
key. Start voice first. On a Protocol 2 Brick, Send holds transmit
for the whole message and puts a carrier on the air for each element.
Power is the Drive slider. The Tune button stays off. The decoder
prints from the host audio the laptop is already playing. MSHV left
running stays a thin line and holds RF.

While the host is in CW, Start voice, the key, MOX, Tune, and 2-tone
stay off at 150 ms or more. Outside CW, voice, MOX, Tune, and 2-tone
stay off at 200 ms or more. The CW lamp is under 150 ms. The Voice
lamp is under 200 ms. A Voice lamp does not allow transmit in CW once
the ping is 150 ms or more.

Tailscale only. Password on every new connection. One desk. Not a
phone or a tether, and not the browser TCI remote. Plan on at least
50 Mbps at each end. Under 25 Mbps is not supported.
Steps: [User Guide → Lyra to Lyra](../help/USER_GUIDE.md#lyra-to-lyra).

## If it misbehaves

Reinstall **v0.25.22** from GitHub. That build has no Lyra-to-Lyra.
Settings stay.

Download **Lyra-Setup-0.25.24.exe**. Windows 10 / 11.
