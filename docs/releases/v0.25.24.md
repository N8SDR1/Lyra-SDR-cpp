# Lyra v0.25.24 — Sheliak

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater sees it.
**v0.25.22** remains the return point if you do not want Lyra-to-Lyra.

## What to try

**Hermes Lite + transverter / IO board (Volker).** On Protocol 1 the Band
dock Xvtr row has **RF1** and **Alt**. Leave **RF1** for the PA / N2ADR
antenna SMA. Click **Alt** only if that slot’s IF is on the Pico / IO
**Alt RX** jack. Station table: User Guide → *Which Hermes Lite station
is mine?* Analog GPA100 band voltage on J4 is unchanged.

**Protocol 2 TX.** DUC I/Q (UDP 1029) no longer shares the radio session
thread. Aimed at the occasional “keyed, relay clicks, no RF until restart”
after a long MSHV / WSJT session. Dummy load on the first Brick key after
install.

Lyra-to-Lyra from **0.25.23** is still in this installer. Same version on
both PCs. Steps: [User Guide → Lyra to Lyra](../help/USER_GUIDE.md#lyra-to-lyra).

## If it misbehaves

Reinstall **v0.25.22** from GitHub. That build has no Lyra-to-Lyra.
Settings stay.

## Install

Download **Lyra-Setup-0.25.24.exe**. Windows 10 / 11.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
