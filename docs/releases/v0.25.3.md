# Lyra v0.25.3 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.2.

## What's new

- **Xvtr VFO / TCI** — frequency LED is ten digits (**MMMM.kkk.hhh**) so
  transverter **RF** is not clipped at **55.999.999 Hz**. Ceiling is the
  signed-int max (~2.147 GHz). TCI `vfo_limits` match.
- Slot editor **RF low/high/LO** were already MHz; that was not the 55 MHz
  stop. **Band-plan region does not rewrite** Xvtr slots — set 144–146
  vs 144–148 for your allocation. Keep **IF** = RF − LO inside the HL2
  native window (~DC–30.72 MHz).
- In-app **Help** has a dedicated **Xvtr (transverters)** section.
