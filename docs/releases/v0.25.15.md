# Lyra v0.25.15 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.14.

## What's new

- **Protocol 2 TX follows the VFO after retune.** On BrickSDR2, the first
  TX was on-frequency; after any dial move, TX stayed on the previous
  frequency until the stream was restarted (Greg VK3KV; same 40 m chase
  here). RX1 NCO is now written before the dial-changed notify so the
  DUC sees the new frequency. Same order for SPLIT, VFO B, and XIT.
  Mode and CW pitch re-push the DUC. SSB / CW / AM / FM share the path.
- **Keyboard VFO.** Left / Right steps **1 kHz**, Up / Down **10 Hz**, on
  the focused receiver (SUB + VFO B when that RX is focused). Arrow keys
  still pick digits when the VFO LED has focus. Does not steal keys from
  text fields, dialogs, or combo lists (Greg VK3KV).
- **Startup profile follows the restored mode.** Last session's FM (or
  CW / AM / …) no longer gets overwritten by Default (SSB) on every
  launch. Order: mode-family binding → last-used profile → Default
  (Volker DL1VE).
- **Tuning Mem left-click.** After idle, left-click on Tuning → Mem
  opens the recall list again. Right-click still saves / manages.
  Same handler on Band → Mem (Volker DL1VE).
- **Help.** How to create a profile; MUTE vs VAC/MON echo; Combinator is
  the multiband compressor (no separate CFC); SWR on Tuner pill and Meter.
