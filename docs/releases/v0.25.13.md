# Lyra v0.25.13 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC / Apps) transmit. **Windows only** for this installer.

Star name stays **Sheliak**. Patch over v0.25.12.

## What's new

- **TCI STOP no longer drops MOX.** WSJT-X / JTDX send STOP when TCI RX
  audio goes silent during TX. 0.25.11 stopped closing the radio on that
  command, but still unkeyed. STOP echoes `start` while the session is
  running. TUNE/TRX still need **▶ Start**.

v0.25.12 Rec folder and v0.25.11 FFTW-before-companions stay in this tree.
