# Lyra v0.24.3

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

A patch on v0.24.2: **startup hang on some GPUs**, **HL2 Band Volts on
J3**, Brick **SPLIT** polish, TCI **VFO B / RX2**, and Protocol 2
**classic ANAN** profiles (dummy-load TX).

## Startup (#16)

- Graphics crash-ladder recoveries (OpenGL, then software) **no longer
  request 4× MSAA**. Software + 4× samples hung QQuickWidget swapchains
  on some Intel UHD machines — log died after USB-BCD open, no window.
- Extra `[startup]` lines after USB-BCD so a hang is easier to spot.
- If Lyra still never appears: `lyra.exe --safe`, then pick a backend in
  **Settings → Visuals**.

## HL2 Band Volts / IO board (#14)

- **J3** = gateware Band Volts on **GPIO04_Fan** (DeskHPSDR dither bit /
  MI0BOT *HL2 Band Volts*). Tick **HL2 Band Volts on J3**, Stop/Start,
  gateware ≥72p5. Default remains **off**.
- **Enable N2ADR / IO board** = OC → Pico PWM analog (stock firmware
  **J4 pin 8**), not J3.
- A persisted Band Volts ON is **re-seeded when the stream opens**, so it
  actually reaches C0=0x00 C3 bit 3.

## BrickSDR2 operating (since v0.24.2)

- Independent **SPLIT** (TX on VFO B) with gray TX pips, right-click
  1/5/10 kHz shift, lime TX marker, off-span **◀ TX**.
- TCI: `vfo:0,1` = SPLIT VFO B; `vfo:1,0` / `dds:1` = SUB; calibrated
  RX2 S-meter on `rx_channel_sensors:1`. Combo RST still RX1.
- Band chips: Shift/right-click hops **SUB** with its own last-freq.

## ANAN Protocol 2

- **ANAN-10 / 10E / 100 / 100B / 100D / 200D** get classic-Alex P2
  profiles (deskHPSDR HPF). Pick the marketed model in Settings —
  discovery **Hermes** still defaults to BrickSDR2.
- TX is **dummy-load until that box is on-air validated**. Leftover P1
  ANAN is refused. **7000DLE / 8000** stay locked.
