# Lyra v0.25.21 — Sheliak · Lyra Remote

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.20.

## What's new since v0.25.20

- **Lyra Remote.** A separate browser desk. Download it from
  [Lyra Remote releases](https://github.com/N8SDR1/Lyra-Remote/releases).
  How the page works is in the
  [Lyra Remote wiki](https://github.com/N8SDR1/Lyra-Remote/wiki).
  Lyra does not host the page, and this installer does not contain it.
  **Settings → Remote** is the password, the address lists, and the
  voice session. The same section is in the in-app guide.
- **Voice session.** **Start voice** on the page proves the password
  once. Then **MOX** uses that browser's microphone and **Tune** sends
  a carrier from Lyra. The desk microphone, rack, and leveler come back
  when the session ends. A digital program on the radio computer is not
  asked for the password. End the voice session before that program
  transmits.
- **Brick3 first key.** The first key after Lyra starts waits until PA
  enable is already in receive, so RF is there without a stop and start.
- **ALC on the TCI meter line.** A fifth number, ALC headroom in dB,
  rides with the TX sensors. It is −200 while receiving. A client that
  reads the first four numbers is unchanged.

## Radios this installer opens

| Radio | Protocol | Notes |
|---|---|---|
| **Hermes Lite 2 / 2+** | 1 | Full RX + TX. |
| **BrickSDR2** | 2 only | Full RX + TX, SUB overlay, PureSignal. |
| **Brick3SDR** | 2 only | **Beta.** Second SUB panadapter. Diversity. First RF: dummy load. |
| **ANAN-10 / 10E** | 2 | TX like BrickSDR2 (on-air). One ADC. |
| **ANAN-100 / 100B** | 2 | TX like Brick3SDR (on-air). One ADC. |
| **ANAN-100D / 200D** | 2 | TX like Brick3SDR + SUB second pane + Diversity. |
| **ANAN-G2 / G2-1K** | 2 | Dummy-load arm until RF validated. |
| **7000DLE / 8000** | — | Locked. |
| Brick / ANAN on **Protocol 1** | 1 | Discover lists; **Open refused**. Flash P2. |

## Install

Download **Lyra-Setup-0.25.21.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio.

The browser desk is a second download:
**[Lyra-Remote](https://github.com/N8SDR1/Lyra-Remote/releases/latest)**.
