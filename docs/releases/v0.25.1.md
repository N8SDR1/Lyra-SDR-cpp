# Lyra v0.25.1 — Sheliak

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

Star name stays **Sheliak**. Patch over v0.25.0 (PureSignal + Amp View).

## What's new

- **NR-C** — occupied bins mixed at full scale so the passband stays
  brick-wall at the edges instead of sloping.
- **Xvtr** — four transverter chips on the band row (RF dial, IF to the
  radio; Shift+click parks SUB; right-click slot editor; Disable PA
  default on).
- **Anti-aliasing (MSAA)** — Settings → Visuals **Off / 2× / 4× / 8×**
  (default 4×). Restart to apply. Safe boot / software renderer stay off.
- **Protocol 1 ANAN / Brick** — Discover still lists the row; **Open is
  refused**. Lyra's P1 TX layout is Hermes Lite only. Flash **Protocol 2**
  if the box can; Brick FPGA help: **Anton (linoobs)** on Discord.
