# Lyra v0.24.5

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

A meatier patch on v0.24.4: stop the graphics crash-ladder from fighting a
**pinned** GPU backend, and store **VAC2** with TX profiles.

## Graphics pin vs crash-ladder

v0.24.4 could leave `ui/gfxStartupPending` set if a dock load looked
incomplete. The next launch then treated that as a crash and stepped
**Auto** toward software — even when Settings already had **Vulkan /
Direct3D / OpenGL** chosen (AMD RX 9070 XT and similar).

- If the backend is **pinned**, leftover safe-mode / ladder keys are
  cleared; the ladder does **not** increment; `LYRA_GRAPHICS` still wins.
- The first successful QML dock load clears the startup-pending latch.
- **Settings → Visuals → Leave safe mode** no longer requires changing the
  combo.

If an older installer left you on software: pick your GPU backend (or
Leave safe mode), Apply, restart.

## VAC2 in TX profiles (schema 6)

Profiles now save VAC2 enable, auto-digital, RX/TX gain, latency, and VAC
size. Devices stay **global**. Pre-v6 files omit VAC2 → VAC2 stays off
until you save again. Apply order: VAC1, then VAC2, then mic source (TCI
still wins).

settings carry over.
