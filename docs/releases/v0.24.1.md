# Lyra v0.24.1

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now (Linux / macOS
planned, not yet buildable).

A patch on v0.24.0 so **PA Gain / Full Output / CAP** actually drive the
Protocol 2 analog path, plus a dedicated **11m** calibration slot and a
handful of TX/RX safety fixes.

## PA Gain, Full Output, and CAP (BrickSDR2)

Settings → **PA Gain** now applies on Protocol 2 the way operators already
used it on the HL2:

- Per-band **PA Gain** and **Full Output (W)** feed analog drive (HP [345]),
  not a leftover Protocol 1 DAC mapping.
- **CAP** can learn and hold a watts ceiling; the TX panel chip shows
  **CAP learn** while it is still gathering, then **CAP nW** when it is
  holding a calibrated band.
- **11m** has its own PA/CAP slot (it is *not* an amateur band-stack /
  OC entry — only a power-calibration row).

Calibrate on a **dummy load** first. Keep the amplifier out of line until
the numbers match an external meter.

## TX while keyed (BrickSDR2)

- **ATT-on-TX** overlays the RX attenuator while you are transmitting
  (front-end protection, same idea as the HL2).
- Brick **DDC0 follows the DUC** while keyed so the panadapter stays on
  the transmit frequency.

## Other fixes since v0.24.0

- **Space** no longer keys MOX when a TX button or the PTT-toggle checkbox
  has focus.
- RX **AGC is frozen across TX**, which removes the unkey “swelling thump.”
- Discovery now **unicasts P1 and P2 probes** to remembered radio IPs
  during auto-scan (helps radios that do not answer a broadcast).

---

**Installer:** the Windows setup now ships the MSVC C runtime next to
`lyra.exe` (so a PC without Visual Studio still launches), plus
`LICENSE` / `NOTICE.md` / `CREDITS.md`. The GPL license is shown in
the setup wizard.

**Upgrade note:** drop-in — install over your existing Lyra; settings and
PA Gain tables carry over. 11m values start at the default (100 / empty
Full Output) until you calibrate that slot.

Dummy-load first on BrickSDR2. ANAN family radios are still planned, not
supported in this installer.
