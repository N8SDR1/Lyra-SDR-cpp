# Lyra v0.24.4

**Hardware / scope:** Hermes Lite 2 / 2+ over HPSDR Protocol 1, and
**BrickSDR2** over Protocol 2. RX plus SSB / AM / DSB / SAM / FM / CW and
digital (TCI / VAC) transmit. **Windows only** for now.

A patch on v0.24.3 aimed at the remaining **startup hang** (GitHub #16) and
a tester-facing **VAC2** cable.

## Startup (#16)

v0.24.3 skipped 4× MSAA on the software crash-ladder. Some Intel UHD
machines still died at `building docks` with a black window — including
when Direct3D 11 was forced.

- QML `QQuickWidget::setSource` now runs **after** the main window is
  shown, one dock at a time (visible panels first, chip-summoned last).
- The log prints each dock as it loads, then `docks ready`.
- Software / graphics-safe-mode also set `QSG_RENDER_LOOP=basic` before
  `QApplication` (required for QQuickWidget + the software scene-graph).

This is a targeted docks-startup fix, not a guarantee on every GPU. If the
window still never appears, try `lyra.exe --safe`, then
**Settings → Visuals**. A registry wipe is **not** required.

## VAC2

A second virtual-audio cable (VAC2) for RX2 audio out and a second PC-mic
TX path (`micpc2`). Settings → Audio. VAC1 is unchanged.
