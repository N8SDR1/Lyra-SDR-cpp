# Lyra v0.25.19 — Sheliak · analog delay=5 · #17

Hermes Lite 2 / 2+ (Protocol 1) and **BrickSDR2 / Brick3SDR** (Protocol 2).
Windows 10 / 11.

This is a **full** GitHub release so the in-app updater and
`/releases/latest` both see it. Star name stays **Sheliak**. Patch over
v0.25.18.

## What's new since v0.25.18

- **HL2 analog band-follow (Issue #17).** v0.25.18 used I2C `delay=0`
  on analog BYTE4..BYTE1. Two 0x1D writes then rode one UDP datagram;
  Pico `n2adr_basic` missed the BYTE0 latch, so **J4 pin 8** stayed
  on leftover PWM (often 20 m) with **zero** voltage change on hops.
  This build restores Thetis/Quisk **delay=5** between every analog
  byte, still drops a leftover 0x1D burst, and only coalesces when
  BYTE0 is actually on the wire.
- **IQ backlog cap** on RX1/RX2 so a stalled drain cannot grow without
  limit. RX2-ground-on-TX is atomic for the wire thread.
- **PC-ring underruns** use a raised-cosine fade instead of a hard
  zero. NB and AF gain are atomics so workers cannot tear them.
- **DIGU/DIGL** below the Drive/Tune sliders toasts the status bar.

## Already in previous versions, still here

Analog leftover-burst drop + BYTE0 latch (v0.25.18, now with delay=5).
RX2 jack isolate on TX, 11 m chips on SUB. Dual-ADC SUB pane, Brick3
TX like BrickSDR2 (v0.25.17). MAP / Auto Step / per-band PS pad
(v0.25.16).

## Install

Download **Lyra-Setup-0.25.19.exe**. Windows 10 / 11. Click **▶ Start**,
pick your radio. Analog testers: dummy/low power, **J4 pin 8**, hop
160 → 80 → 20 → 15. Leave **HL2 Band Volts on J3** off unless the amp
is on the fan header.
